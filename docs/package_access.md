# باكيجات قنبلة الأسئلة

## السلوك الحالي

- إعداد اللاعبين ← اختيار باكيج واحد أو أكثر ← بدء اللعبة.
- 6 باكيجات، لكل منها 24 سؤالًا. «خلطة عامة» و«دول وعواصم» مجانيتان.
- الباكيجات الأخرى تفتح بعد مكافأة إعلان Google اختباري فعلي وإغلاق الإعلان.
- إغلاق الإعلان دون المكافأة، أو فشل الاتصال، أو انتهاء مهلة التحميل لا يفتح شيئًا.
- الفتح خاص باللعبة الحالية، بكل جولاتها. الرجوع لتعديل أسماء اللاعبين يحتفظ بالاختيارات والفتح.
- «نلعب من جديد» من النتائج يبدأ إعدادًا جديدًا ويعيد قفل الباكيجات المدفوعة.
- الأسئلة المختارة تنسخ إلى GameState، وتظل ثابتة عند بدء جولة جديدة.
- الاشتراك معروض كميزة قادمة؛ لا يوجد شراء أو سعر أو اشتراك وهمي في هذه النسخة.

## أماكن التعديل

- `lib/data/question_packages.dart`: الموضوع، مجاني أم مقفول، وأسئلة كل باكيج.
- `lib/models/package_selection.dart`: الاختيار وصلاحية فتح الباكيج أثناء اللعبة.
- `lib/services/rewarded_ad_service.dart`: طلب الإعلان ومعالجة المكافأة والفشل.
- `lib/screens/packages_screen.dart`: اختيار المواضيع ونافذتا الإعلان والاشتراك.

## إعداد الإعلانات

هذه النسخة تستخدم معرفات Google الاختبارية فقط، حسب اختيار صاحب المشروع.
معرفا التطبيق التجريبيان موجودان في AndroidManifest.xml وInfo.plist، ومعرفا
الإعلان المكافئ موجودان في rewarded_ad_service.dart. لا يطلب التطبيق إعلانًا
إلا بعد الضغط صراحة على «شاهد إعلان وافتحها». اللعب المجاني لا ينتظر تهيئة SDK.

قبل تفعيل الربح الفعلي يلزم إدخال معرفات AdMob الخاصة بالتطبيق وإكمال إعداد
الموافقة المناسب للنشر. الاشتراك مؤجل إلى إعداد منتجات المتجر والتحقق من
صلاحية الشراء والاستعادة والانتهاء؛ لا يجوز استخدام علامة محلية كدليل دفع.

## الفحص

`flutter test --no-pub` يشمل منع الوصول للباكيجات المقفولة، حالات المكافأة
والإلغاء والفشل، الأسئلة المختارة، وتجاوب الشاشات. اختبار المؤقت القديم الذي
يحتاج وقتًا فعليًا يبقى اختياريًا. معاينات التصميم تُنشأ بواسطة:

```sh
flutter test test/design_review_test.dart --update-goldens --dart-define=RENDER_DESIGN=true
```
